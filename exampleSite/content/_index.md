**radiance** is a Hugo theme that makes a content website feel like an
Ubuntu desktop running GNOME 2: compact panels, small windows and quiet
utility dialogs.

This example site contains a small collection of sample posts. Use the
links in the top panel or the desktop shortcuts to browse them.
