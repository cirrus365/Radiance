A factual checklist for distributing the theme. Nothing here is a promise of results; it is the list of places that make sense and the preparation each one needs.

Hugo themes gallery

The theme’s theme.toml already carries the metadata the gallery lists: name, licence, description, minimum Hugo version, tags and features. Before submitting, replace the OWNER placeholders with the real repository path, confirm the live demo URL and check the gallery’s submission guidance for screenshot requirements.

Show HN or Lobsters

The framing that matches the project is the nostalgia and the engineering, not the theme-market angle: a GNOME 2 desktop as a website, window management deliberately removed, one source of truth per fact, no dependencies. Lobsters’ retro-computing and ricing communities are the closer fit; post with the demo link and be ready to discuss the decisions in the case study.

Mastodon

A short post with a screenshot or short clip of the toggle switching schemes, plus the demo and repository links. The small-web and Hugo hashtags reach the audience that installs themes like this one.

Small-web communities

IndieWeb, 32-bit Cafe and similar communities fit the theme’s positioning: personal sites, hand-rolled pages, no build pipeline dependency beyond Hugo. Offer the theme as a starting point for personal homepages, and link the “who it is for” chapter so people can self-select.

Before any of it

  • the demo builds clean with --panicOnWarning;
  • the contrast report passes for every shipped scheme;
  • the README is the short landing page and the handbook is complete;
  • the repository path placeholders are gone.
