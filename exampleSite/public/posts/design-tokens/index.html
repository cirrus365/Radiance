Design tokens

8 November 2026

Tags Colour, Gnome

All authored colour values in radiance live in assets/css/tokens.css. Every other stylesheet refers to the custom properties defined there, for example:

a {
  color: var(--radiance-accent);
}

Starting palette

The starting palette takes its cues from Ubuntu’s Radiance theme:

  • Pale panels with fine borders.
  • A deep aubergine desktop with purple and orange highlights.
  • An orange accent for links and selection.

These are starting values, not a guarantee of accessible contrast; adjust them when a combination needs improvement.

Dark appearance

The Ambiance dark appearance ships alongside the light one: choose it from the System menu, or let the operating system decide. Both appearances are built from the same tokens file.
