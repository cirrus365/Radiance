Getting started

1 November 2026

Tags Gnome

Prerequisites

radiance needs Hugo Extended 0.128.0 or newer. Check the installed version:

hugo version

Build the example site

The theme repository ships an example site:

hugo --source exampleSite --themesDir ../..

The command assumes the theme checkout directory is named radiance, so that ../.. resolves from exampleSite to the directory containing the theme.
