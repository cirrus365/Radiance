{{/* index.html — the homepage: a profile card in a single window. Front matter read by this layout: greeting (string, required): the complete greeting sentence, present as visually hidden text so assistive technology never receives the partially typed string. typed (string, required): the one short line the greeting types out, character by character, through JavaScript; without JavaScript (or with reduced motion) it renders finished immediately. The server-rendered text reserves the height, so the reveal causes no layout shift. doors (list, optional): prominent links under the intro; each entry carries "label" and "href" (site-absolute or external). featured (list, optional): pageRefs surfaced below the recent posts; entries whose pageRef does not resolve are skipped. title, description, draft: standard Hugo page fields. The intro paragraph is the page's ordinary Markdown content. The window's status bar shows the page's word count and last-modified date, both derived at build time. Three recent dated pages (utility pages excluded) follow the intro. Nothing here is hardcoded personality: every word and link comes from the content file. */}} {{- define "main" -}} {{- $recent := slice }} {{- range first 10 (sort (where site.RegularPages "Params.utility" "!=" true) "Date" "desc") }} {{- if and (lt (len $recent) 3) (gt .Date.Year 1) }} {{- $recent = $recent | append . }} {{- end }} {{- end }} {{- $statusbar := printf "

%d wordsLast modified %s

" .WordCount (.Lastmod.Format "2006-01-02") (.Lastmod | time.Format ":date_long") | safeHTML }} {{- $greeting := printf "

%s%s

" (.Params.greeting | transform.XMLEscape) (.Params.typed | transform.XMLEscape) }} {{- $doors := partial "profile-doors.html" (dict "doors" .Params.doors) }} {{- $featured := partial "profile-featured.html" (dict "featured" .Params.featured) }} {{- $content := printf "
%s%s%s%s%s
" $greeting .Content $doors (partial "profile-posts.html" (dict "pages" $recent)) $featured | safeHTML }} {{- partial "window.html" (dict "title" "welcome.txt" "id" "window-profile" "icon" "computer" "content" $content "statusbar" $statusbar) -}} {{- end -}}
